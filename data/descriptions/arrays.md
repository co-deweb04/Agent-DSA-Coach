1. Array Fundamentals
Description:
Understand how to represent a collection of elements using an array, access elements by index, and identify the time complexity of common array operations such as access, search, insertion, deletion, and traversal.
2. Array Traversal
Description:
Given an array, traverse all its elements and perform the required operation on each element, such as finding a value, calculating a sum, counting elements, or updating values.
3. Finding Maximum and Minimum
Description:
Given an unsorted array, find the largest and smallest elements by examining the elements efficiently without using unnecessary additional storage.
4. Linear Search
Description:
Given an array and a target value, search through the elements sequentially and determine whether the target exists and, if required, return its position.
5. Two Pointer Technique
Description:
Given an array, use two indices to process elements efficiently, particularly when finding pairs, comparing elements from opposite ends, reversing an array, or solving problems involving sorted data.
6. Sliding Window
Description:
Given an array and a problem involving a contiguous or consecutive range, maintain a moving window to calculate the required result efficiently instead of repeatedly processing the same elements.
7. Prefix Sum
Description:
Given an array and multiple range-sum queries, preprocess the array so that the sum of any specified range can be calculated efficiently without repeatedly traversing the range.
8. Hashing with Arrays
Description:
Given an array, determine whether elements have appeared previously or efficiently locate required values by storing encountered elements in a hashing-based data structure.
9. Frequency Counting
Description:
Given an array or collection of values, determine how many times each distinct element occurs and use these frequencies to solve tasks such as finding duplicates, repeated elements, or the most frequent value.
10. Kadane's Algorithm
Description:
Given an array containing positive and negative integers, find the contiguous subarray having the maximum possible sum and return its maximum sum.
11. Binary Search
Description:
Given a sorted array and a target value, efficiently determine whether the target exists and return its position by repeatedly reducing the search space.
12. Sorting as a Preprocessing Technique
Description:
Given an array problem where ordering the elements can simplify the solution, determine whether sorting should be performed first and then use the sorted order to efficiently solve the required task.
13. In-Place Array Operations
Description:
Given an array and an operation that modifies its elements, perform the required changes directly within the original array while using constant or minimal extra space.
14. Reverse an Array
Description:
Given an array, reverse the order of its elements so that the first element becomes the last and the last becomes the first, preferably without using an additional array.
15. Removing Duplicates from a Sorted Array
Description:
Given a sorted array containing duplicate values, remove the repeated elements in-place so that each unique value appears only once while preserving the sorted order.
16. Move Zeroes
Description:
Given an array containing zero and non-zero elements, move all zeroes to the end while maintaining the relative order of the non-zero elements and performing the operation in-place.
17. Best Time to Buy and Sell Stock
Description:
Given an array representing stock prices on different days, determine the maximum profit that can be achieved by choosing one day to buy and a later day to sell.
18. Product of Array Except Self
Description:
Given an array of integers, construct a new result where each position contains the product of every element except the element at that same position, without using division.
19. Subarrays
Description:
Given an array, identify or process contiguous portions of the array according to the problem requirement, such as finding a subarray with a particular sum, maximum value, or length.
20. Array Problem-Solving Workflow
Description:
Given an array problem, identify the input, output, constraints, possible brute-force solution, and suitable optimization technique before implementing the final solution.
21. Common Array Mistakes
Description:
Analyze an array solution and identify potential errors such as incorrect indices, boundary conditions, duplicate handling, unnecessary time complexity, or failure to handle empty and single-element arrays.
22. Array Pattern Recognition
Description:
Given an array problem, identify the underlying problem-solving pattern, such as two pointers, sliding window, hashing, prefix sum, binary search, sorting, or dynamic programming, and select the most appropriate technique.
23. Brute Force vs Optimized Solution
Description:
Given an array problem, first develop a straightforward brute-force solution and then identify its performance bottleneck and improve it using a more efficient algorithm or data structure.
24. Array Edge Cases
Description:
Given an array-based problem, identify and correctly handle special cases such as empty arrays, single elements, duplicate values, negative numbers, sorted arrays, reverse-sorted arrays, and large inputs.
25. DSA Coach Hint Philosophy
Description:
Given a DSA problem, provide progressively stronger hints that guide the learner from understanding the concept to identifying the pattern, developing the algorithm, writing pseudocode, and finally reaching the complete solution.
26. Important Array Patterns
Description:
Given an array problem, identify which common problem-solving pattern applies, such as traversal, hashing, two pointers, sliding window, prefix sum, binary search, sorting, Kadane's algorithm, prefix/suffix techniques, or in-place manipulation.
