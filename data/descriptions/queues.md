🚶 Queues — Descriptions
1. Queue Operations
Description:
Implement a queue that supports adding elements at the rear, removing elements from the front, viewing the front element, and checking whether the queue is empty.
2. Implement Queue Using Array
Description:
Design a queue using an array and implement enqueue and dequeue operations while correctly managing the front and rear positions.
3. Implement Queue Using Linked List
Description:
Implement a queue using linked-list nodes so that elements can be inserted at the rear and removed from the front efficiently.
4. Circular Queue
Description:
Implement a queue in which the rear can wrap around to the beginning of the array so that previously unused positions can be reused.
5. Queue Using Two Stacks
Description:
Implement FIFO queue operations using two stacks while maintaining the correct order of elements.
6. Stack Using Two Queues
Description:
Implement LIFO stack operations using two queues while ensuring that the most recently inserted element is removed first.
7. Reverse a Queue
Description:
Given a queue, reverse the order of its elements while preserving the queue structure.
8. Generate Binary Numbers
Description:
Generate the first N binary numbers in increasing order using a queue-based approach.
9. First Non-Repeating Character in a Stream
Description:
Given characters arriving one at a time, determine the first character that has not been repeated after each new character is received.
10. Sliding Window Maximum
Description:
Given an array and a window size K, find the maximum element in every contiguous window of size K.
11. Level Order Traversal
Description:
Given a binary tree, visit its nodes level by level from top to bottom using a queue.
12. Rotten Oranges
Description:
Given a grid containing fresh and rotten oranges, determine the minimum time required for all reachable fresh oranges to become rotten.
13. First Negative Number in Every Window
Description:
Given an array and a window size K, find the first negative element in each contiguous window.
14. Priority Queue
Description:
Design a queue where elements are removed according to their priority rather than simply following their insertion order.
15. Task Scheduling
Description:
Given a collection of tasks arriving at different times, process them according to the specified scheduling order while maintaining the required queue behavior.
