🔍 Searching — Descriptions
1. Linear Search
Description: Search for a target element by checking each element of the collection sequentially until the target is found or the collection ends.
2. Find First Occurrence
Description: Find the index of the first position at which the target element appears in the array.
3. Find Last Occurrence
Description: Find the index of the final position at which the target element appears in the array.
4. Count Occurrences
Description: Count how many times a specified target element occurs in the given array.
5. Binary Search
Description: Search for a target value in a sorted array by repeatedly dividing the search space into two halves.
6. First Occurrence Using Binary Search
Description: Find the first occurrence of a target in a sorted array containing duplicate values while maintaining logarithmic search time.
7. Last Occurrence Using Binary Search
Description: Find the last occurrence of a target in a sorted array containing duplicate values using binary search.
8. Search Insert Position
Description: Given a sorted array and a target, determine the index where the target exists or should be inserted to maintain sorted order.
9. Find Square Root
Description: Given a non-negative integer, find its integer square root without using a direct square-root function.
10. Search in Rotated Sorted Array
Description: Find the position of a target element in a sorted array that has been rotated at an unknown position.
11. Find Peak Element
Description: Find an element that is greater than its adjacent elements, treating that element as a peak.
12. Find Minimum in Rotated Sorted Array
Description: Find the smallest element in a sorted array that has been rotated while keeping the solution efficient.
13. Find Missing Number
Description: Given numbers from a specified range with exactly one number missing, determine which number is absent.
14. Find Majority Element
Description: Find the element that occurs more than half the number of times in the given array.
15. Search in 2D Matrix
Description: Search for a target value in a matrix whose elements follow a specified sorted arrangement.
