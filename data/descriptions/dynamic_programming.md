🧠 Dynamic Programming — Descriptions
1. Fibonacci Using Dynamic Programming
Description: Calculate the Nth Fibonacci number while avoiding repeated calculations by storing the results of previously solved subproblems.
2. Climbing Stairs
Description: Determine the number of distinct ways to reach the top of a staircase when you can climb either one or two steps at a time.
3. House Robber
Description: Find the maximum amount of money that can be collected from a sequence of houses without selecting two adjacent houses.
4. Maximum Sum Subarray
Description: Find the contiguous subarray that has the maximum possible sum among all subarrays.
5. Coin Change
Description: Given a set of coin denominations and a target amount, determine the minimum number of coins required to make that amount.
6. Coin Change — Number of Ways
Description: Determine the number of different combinations of the given coins that can be used to form the target amount.
7. 0/1 Knapsack
Description: Select items with given weights and values to maximize total value without exceeding the capacity, with each item allowed to be selected at most once.
8. Longest Common Subsequence
Description: Find the longest sequence of characters that appears in both strings in the same relative order, without requiring the characters to be consecutive.
9. Longest Increasing Subsequence
Description: Find the longest subsequence in which every selected element is greater than the element selected immediately before it.
10. Edit Distance
Description: Determine the minimum number of insertions, deletions, and replacements required to transform one string into another.
11. Partition Equal Subset Sum
Description: Determine whether the given array can be divided into two subsets whose elements have equal total sums.
12. Subset Sum
Description: Determine whether there exists a subset of the given elements whose total sum is exactly equal to the specified target.
13. Minimum Path Sum
Description: Find the path from the top-left cell to the bottom-right cell of a grid that produces the minimum possible sum while following the allowed movements.
14. Unique Paths
Description: Calculate the number of distinct paths from the top-left corner to the bottom-right corner of a grid when movement is restricted to the allowed directions.
15. Matrix Chain Multiplication
Description: Determine the order in which a sequence of matrices should be multiplied so that the total number of scalar multiplication operations is minimized.
