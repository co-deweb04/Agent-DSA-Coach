1. Median of Two Sorted Arrays
Description: Given two sorted arrays, determine the median of all their elements combined while achieving the required logarithmic-time complexity.
2. Merge k Sorted Lists
Description: Given k sorted linked lists, merge all of them into one sorted linked list while maintaining the overall ordering.
3. Trapping Rain Water
Description: Given an array representing elevations, determine the total amount of rainwater that can be trapped between the elevation bars.
4. N-Queens
Description: Place n queens on an n × n chessboard so that no two queens attack each other, and return all valid board configurations.
5. Word Ladder
Description: Given a starting word, a target word, and a dictionary, determine the shortest transformation sequence where each step changes exactly one character and produces a valid word.
6. Minimum Window Substring
Description: Given two strings, find the smallest substring of the first string that contains all required characters from the second string with the necessary frequencies.
7. Sliding Window Maximum
Description: Given an integer array and a window size k, find the maximum element inside every contiguous window of that size.
8. Largest Rectangle in Histogram
Description: Given the heights of adjacent histogram bars, determine the largest rectangular area that can be formed using consecutive bars.
9. Serialize and Deserialize Binary Tree
Description: Design a method to convert a binary tree into a storable string representation and another method to reconstruct the original tree from that representation.
10. Word Search II
Description: Given a character grid and a collection of words, find all words that can be formed by connecting adjacent cells without using the same cell more than once for a word.
11. Regular Expression Matching
Description: Given a string and a pattern containing . and *, determine whether the entire string matches the pattern according to the specified matching rules.
12. Edit Distance
Description: Given two strings, determine the minimum number of insertions, deletions, and character replacements needed to transform the first string into the second.
13. Binary Tree Maximum Path Sum
Description: Given a binary tree containing positive or negative values, find the maximum possible sum of values along any valid path between nodes.
14. Distinct Subsequences
Description: Given two strings, determine how many distinct subsequences of the first string are equal to the second string.
15. Minimum Number of Refueling Stops
Description: Given a target distance, an initial amount of fuel, and fuel stations along the route, determine the minimum number of refueling stops needed to reach the destination.
