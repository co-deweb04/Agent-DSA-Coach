🕸️ Graphs — Descriptions
1. Graph Representation
Description: Represent the given graph using an appropriate structure such as an adjacency list or adjacency matrix.
2. Breadth First Search
Description: Traverse all reachable vertices of a graph level by level starting from a specified source vertex.
3. Depth First Search
Description: Traverse the graph by exploring as deeply as possible along each path before backtracking.
4. Detect Cycle in Undirected Graph
Description: Determine whether an undirected graph contains a cycle by examining connections between visited vertices and their parents.
5. Detect Cycle in Directed Graph
Description: Determine whether a directed graph contains a cycle by identifying a path that leads back to a previously active vertex.
6. Number of Connected Components
Description: Determine how many separate groups of connected vertices exist in an undirected graph.
7. Number of Islands
Description: Given a grid containing land and water cells, count the number of separate connected groups of land cells.
8. Shortest Path in an Unweighted Graph
Description: Find the minimum number of edges required to travel from a given source vertex to a destination vertex.
9. Bipartite Graph
Description: Determine whether the vertices of a graph can be divided into two groups such that no two connected vertices belong to the same group.
10. Topological Sorting
Description: Find an ordering of vertices in a directed acyclic graph such that every vertex appears before all vertices that depend on it.
11. Course Schedule
Description: Given courses and their prerequisite relationships, determine whether all courses can be completed without creating a circular dependency.
12. Dijkstra's Shortest Path
Description: Find the shortest distance from a source vertex to other vertices in a weighted graph where edge weights are non-negative.
13. Minimum Spanning Tree
Description: Connect all vertices of a weighted undirected graph with the minimum possible total edge weight without creating cycles.
14. Flood Fill
Description: Starting from a specified cell, change the color of that cell and all connected cells having the same original color.
15. Word Ladder
Description: Find the shortest sequence of valid words that transforms a starting word into a target word by changing one character at a time.
