1. Add Two Numbers
Description: Given two non-empty linked lists representing non-negative integers in reverse digit order, add the two numbers and return the result as a linked list.
2. Longest Substring Without Repeating Characters
Description: Given a string, find the length of the longest contiguous substring in which every character appears only once.
3. 3Sum
Description: Given an integer array, find all unique combinations of three different elements whose sum is zero.
4. Container With Most Water
Description: Given an array representing vertical lines, choose two lines that form a container capable of holding the maximum amount of water.
5. Group Anagrams
Description: Given an array of strings, group together strings that contain the same characters with the same frequencies.
6. Product of Array Except Self
Description: Given an integer array, construct an output array where each position contains the product of every input element except the element at that position.
7. Top K Frequent Elements
Description: Given an integer array, identify the k elements that occur most frequently.
8. Longest Palindromic Substring
Description: Given a string, find the longest contiguous substring that forms a palindrome.
9. Search in Rotated Sorted Array
Description: Given a sorted array that has been rotated and a target value, find the target's index using an efficient search approach.
10. Coin Change
Description: Given coin denominations and a target amount, determine the minimum number of coins required to make that amount, or indicate when it cannot be formed.
11. Number of Islands
Description: Given a grid containing land and water cells, count the number of separate connected groups of land cells.
12. Clone Graph
Description: Given a reference to a node in a connected graph, create a deep copy of the entire graph while preserving the same connections between cloned nodes.
13. Course Schedule
Description: Given courses and their prerequisite relationships, determine whether all courses can be completed without encountering a circular dependency.
14. Binary Tree Level Order Traversal
Description: Given the root of a binary tree, return the values of its nodes grouped according to their levels from top to bottom.
15. Kth Largest Element
Description: Given an unsorted integer array, find the element that would have the kth largest position if the values were arranged in descending order.
