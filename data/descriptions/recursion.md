🔁 Recursion — Descriptions
1. Factorial Using Recursion
Description: Calculate the factorial of a given number by repeatedly reducing the problem to the factorial of a smaller number.
2. Fibonacci Number
Description: Find the Nth Fibonacci number by recursively calculating the two preceding Fibonacci values.
3. Sum of First N Numbers
Description: Calculate the sum of all integers from 1 to N using recursive calls.
4. Power of a Number
Description: Calculate the result of raising a number to a given power using recursive multiplication or an optimized recursive approach.
5. Reverse a String
Description: Reverse the characters of a string by recursively processing smaller portions of the string.
6. Check Palindrome Recursively
Description: Determine whether a string is a palindrome by recursively comparing characters from both ends.
7. Sum of Digits
Description: Calculate the sum of all digits in a number by extracting one digit at a time through recursive calls.
8. Count Digits
Description: Determine the number of digits in an integer by recursively removing one digit during each call.
9. Greatest Common Divisor
Description: Find the greatest common divisor of two numbers using the recursive form of Euclid's algorithm.
10. Binary Search Recursively
Description: Search for a target in a sorted array by recursively reducing the search range to one half.
11. Generate All Subsequences
Description: Generate every possible subsequence of a given string by deciding recursively whether each character should be included or excluded.
12. Generate Permutations
Description: Generate all possible arrangements of the characters or elements by recursively selecting and arranging each element.
13. Tower of Hanoi
Description: Move all disks from one rod to another while following the rules that only one disk can be moved at a time and a larger disk cannot be placed on a smaller disk.
14. Count Paths in a Grid
Description: Calculate the number of possible paths from the starting cell to the destination when movement is restricted to the allowed directions.
15. Solve Maze Using Backtracking
Description: Find a valid path from the starting point to the destination by recursively exploring possible directions and backtracking when a path fails.
