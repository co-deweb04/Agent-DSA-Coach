🔤 Strings — Descriptions
1. String Fundamentals
Description:
Understand how to work with strings and perform basic operations such as accessing characters, traversing the string, comparing strings, concatenating values, and finding the length.
2. Reverse a String
Description:
Given a string, reverse the order of its characters and produce the resulting string.
3. Check Palindrome
Description:
Given a string, determine whether it reads the same from left to right and right to left.
4. Count Character Frequency
Description:
Given a string, count how many times each character appears and identify the required character based on its frequency.
5. Find First Non-Repeating Character
Description:
Given a string, find the first character that appears exactly once in the entire string.
6. Check Anagram
Description:
Given two strings, determine whether they contain the same characters with the same frequencies, regardless of their order.
7. Remove Duplicate Characters
Description:
Given a string, remove repeated characters while preserving the required order of the remaining characters.
8. Longest Substring Without Repeating Characters
Description:
Given a string, find the length of the longest substring that contains no repeated characters.
9. Longest Common Prefix
Description:
Given an array of strings, find the longest prefix that is common to all the strings.
10. Valid Parentheses
Description:
Given a string containing different types of brackets, determine whether every opening bracket is correctly matched and closed in the proper order.
11. String Compression
Description:
Given a string containing repeated characters, compress consecutive occurrences into a shorter representation while following the required encoding format.
12. Check String Rotation
Description:
Given two strings, determine whether the second string can be obtained by rotating the characters of the first string.
13. Count Words in a String
Description:
Given a sentence, determine the number of individual words while correctly handling spaces and other separators.
14. Longest Palindromic Substring
Description:
Given a string, find the longest contiguous substring that forms a palindrome.
15. String Pattern Matching
Description:
Given a text and a pattern, determine whether the pattern occurs in the text and, if required, return its starting position.
