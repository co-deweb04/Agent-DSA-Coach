🥞 Stacks — Descriptions
1. Stack Operations
Description:
Implement a stack that supports inserting an element, removing the top element, viewing the top element, and checking whether the stack is empty.
2. Implement Stack Using Array
Description:
Design a stack using an array and implement the required push, pop, peek, and empty-check operations while handling overflow and underflow conditions.
3. Implement Stack Using Linked List
Description:
Implement a stack using linked-list nodes and perform insertion and deletion from the end that represents the top of the stack.
4. Reverse a String Using Stack
Description:
Given a string, use stack operations to reverse its characters and produce the reversed string.
5. Balanced Parentheses
Description:
Given an expression containing brackets, determine whether all opening brackets have matching closing brackets in the correct order.
6. Min Stack
Description:
Design a stack that supports normal push and pop operations while also returning the minimum element currently present in constant time.
7. Next Greater Element
Description:
Given an array, find the first element to the right of each element that is greater than it, using a stack-based approach.
8. Previous Greater Element
Description:
Given an array, find the nearest element to the left of each element that is greater than it.
9. Next Smaller Element
Description:
Given an array, find the first smaller element to the right of each element or report that no such element exists.
10. Evaluate Postfix Expression
Description:
Given a postfix mathematical expression, evaluate it using a stack while correctly applying each operator to its operands.
11. Infix to Postfix
Description:
Given an infix mathematical expression, convert it into postfix notation while maintaining the correct operator precedence and associativity.
12. Remove Adjacent Duplicates
Description:
Given a string, repeatedly remove adjacent equal characters until no such pair remains.
13. Stock Span
Description:
Given daily stock prices, determine for each day the number of consecutive previous days for which the price was less than or equal to the current price.
14. Largest Rectangle in Histogram
Description:
Given the heights of histogram bars, find the largest rectangular area that can be formed using one or more consecutive bars.
15. Implement Two Stacks in One Array
Description:
Design an array-based structure capable of storing two independent stacks while making efficient use of the available space.
