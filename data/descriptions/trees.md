🌳 Trees — Descriptions
1. Tree Traversal
Description:
Given a tree, visit all its nodes using an appropriate traversal technique and produce the nodes in the required order.
2. Inorder Traversal
Description:
Given a binary tree, visit the left subtree, root node, and right subtree in that order and return the resulting sequence.
3. Preorder Traversal
Description:
Given a binary tree, visit the root node before recursively processing its left and right subtrees.
4. Postorder Traversal
Description:
Given a binary tree, process the left and right subtrees before visiting the root node.
5. Level Order Traversal
Description:
Given a binary tree, visit its nodes level by level from the root toward the deepest level.
6. Find Height of a Tree
Description:
Given a tree, determine the maximum number of edges or nodes along a path from the root to a leaf according to the definition used.
7. Count Nodes
Description:
Given a binary tree, calculate the total number of nodes present in the tree.
8. Count Leaf Nodes
Description:
Given a tree, determine the number of nodes that do not have any children.
9. Search in Binary Search Tree
Description:
Given a Binary Search Tree and a target value, determine whether the target exists by using the ordering property of the tree.
10. Insert into Binary Search Tree
Description:
Given a Binary Search Tree and a new value, insert the value at the correct position while maintaining the BST property.
11. Delete from Binary Search Tree
Description:
Given a Binary Search Tree and a target node, remove the node while preserving the BST ordering property.
12. Check Valid Binary Search Tree
Description:
Given a binary tree, determine whether it satisfies the rules of a valid Binary Search Tree for all its nodes.
13. Find Minimum and Maximum
Description:
Given a Binary Search Tree, find the smallest and largest values by using the ordering relationship between the left and right subtrees.
14. Lowest Common Ancestor
Description:
Given two nodes in a tree, find the lowest node that is an ancestor of both given nodes.
15. Diameter of a Binary Tree
Description:
Given a binary tree, determine the length of the longest path between any two nodes in the tree.
