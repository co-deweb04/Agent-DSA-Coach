#️⃣ Hashing — Descriptions
1. Frequency of Elements
Description: Count how many times each distinct element appears in the given collection.
2. Find Duplicate Elements
Description: Identify all elements that occur more than once in the given array.
3. Find First Repeating Element
Description: Find the first element encountered from left to right that appears more than once.
4. Find First Non-Repeating Element
Description: Find the first element whose frequency is exactly one in the given collection.
5. Two Sum
Description: Find two elements whose values add up to the given target and return their required positions or values.
6. Intersection of Two Arrays
Description: Find the elements that are present in both arrays according to the duplicate-handling rule specified by the problem.
7. Union of Two Arrays
Description: Combine the elements from both arrays while removing duplicate values to produce their union.
8. Longest Consecutive Sequence
Description: Find the length of the longest sequence of consecutive integers present in the array, regardless of their original order.
9. Subarray with Given Sum
Description: Determine whether a contiguous subarray exists whose elements add up to the specified target sum.
10. Count Subarrays with Given Sum
Description: Count the number of contiguous subarrays whose sum is exactly equal to the given target value.
11. Group Anagrams
Description: Group strings together when they contain the same characters with the same frequencies, regardless of their order.
12. Isomorphic Strings
Description: Determine whether characters from one string can be mapped consistently and uniquely to characters in another string.
13. Longest Substring Without Repeating Characters
Description: Find the maximum length of a substring in which no character occurs more than once.
14. Common Elements with Frequencies
Description: Find the elements that occur in both arrays while considering how many times each element appears.
15. Detect Duplicate Within K Distance
Description: Determine whether any value appears more than once within a distance of K indices in the array.
