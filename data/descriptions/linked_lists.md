🔗 Linked List — Descriptions
1. Linked List Traversal
Description: Traverse the linked list from the head to the end and visit every node exactly once.
2. Insert Node at Beginning
Description: Given a linked list and a new value, insert the new node before the current head and make it the new first node.
3. Insert Node at End
Description: Given a linked list and a new value, add the new node after the current last node without changing the existing order.
4. Insert Node at a Given Position
Description: Insert a new node at the specified position while maintaining the connections between all existing nodes.
5. Delete Node from Beginning
Description: Remove the first node of the linked list and update the head so that it points to the next node.
6. Delete Node from End
Description: Remove the last node of the linked list and make the second-last node point to NULL.
7. Search an Element
Description: Given a target value, traverse the linked list and determine whether a node containing that value exists.
8. Find Length of Linked List
Description: Traverse the linked list and count the total number of nodes present.
9. Reverse a Linked List
Description: Reverse the direction of all links so that the last node becomes the first node while preserving all elements.
10. Find Middle Node
Description: Find the middle node of a linked list without unnecessarily traversing the list multiple times.
11. Detect Cycle
Description: Determine whether the linked list contains a cycle in which a node eventually points back to a previously visited node.
12. Remove Cycle
Description: Detect the cycle in a linked list and modify the appropriate link to break the cycle and restore a normal list.
13. Merge Two Sorted Linked Lists
Description: Combine two sorted linked lists into one sorted linked list while maintaining the ascending order of elements.
14. Remove Duplicates from Sorted List
Description: Remove repeated values from a sorted linked list so that each value appears only once.
15. Check if Linked List is Palindrome
Description: Determine whether the sequence of values in the linked list reads the same from beginning to end and from end to beginning.
