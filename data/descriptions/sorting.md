🔃 Sorting — Descriptions
1. Bubble Sort
Description: Sort the array by repeatedly comparing adjacent elements and swapping them whenever they are in the wrong order.
2. Selection Sort
Description: Sort the array by repeatedly finding the smallest element from the unsorted portion and placing it at its correct position.
3. Insertion Sort
Description: Sort the array by taking one element at a time and inserting it into its appropriate position within the already sorted portion.
4. Merge Sort
Description: Sort the array by recursively dividing it into smaller parts and merging the sorted parts back together.
5. Quick Sort
Description: Sort the array by selecting a pivot, partitioning elements around it, and recursively sorting the resulting partitions.
6. Sort an Array of 0s, 1s and 2s
Description: Rearrange an array containing only 0, 1, and 2 so that all 0s appear first, followed by 1s and then 2s.
7. Sort by Frequency
Description: Rearrange the elements according to their frequency of occurrence while following the ordering rule specified by the problem.
8. Find Kth Smallest Element
Description: Determine the element that would appear at the Kth position when the array is arranged in ascending order.
9. Find Kth Largest Element
Description: Determine the element that would appear at the Kth position when the array is arranged in descending order.
10. Merge Overlapping Intervals
Description: Given a collection of intervals, combine all intervals that overlap and return the resulting non-overlapping intervals.
11. Sort Strings Alphabetically
Description: Arrange the given collection of strings in lexicographical or dictionary order.
12. Sort Characters by Frequency
Description: Rearrange the characters of a string according to their frequency of occurrence.
13. Sort Nearly Sorted Array
Description: Sort an array where every element is at most K positions away from its correct sorted position.
14. Count Inversions
Description: Count the number of pairs of elements where a larger element appears before a smaller element in the array.
15. Sort Array by Parity
Description: Rearrange the array so that elements satisfying the even condition appear before elements satisfying the odd condition.
